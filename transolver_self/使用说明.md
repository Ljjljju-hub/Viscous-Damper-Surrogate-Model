# Transolver 使用说明

## 1. 使用范围

本说明用于：

1. 检查数据是否可用于训练；
2. 启动、监控和恢复 Transolver 训练；
3. 使用 checkpoint 做时间序列 rollout；
4. 读取带动态网格的预测结果；
5. 与 MeshGraphNet 进行同口径比较。

内部原理见 `transolver_self/技术文档.md`。

## 2. 环境

后续统一使用 `conda pinn` 环境：

```powershell
conda activate pinn
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
```

也可以直接使用解释器：

```powershell

```

本实现依赖与 MeshGraphNet 相同：

```text
torch
torch-geometric
h5py

```

不需要安装官方实现中的 `timm` 和 `einops`。

## 3. 目录检查

在项目根目录执行：

```powershell
Get-ChildItem "计算有限元数据\comsol_hdf5" -Filter *.h5 | Measure-Object
Test-Path "计算有限元数据\4_Combined_Master_Dataset.json"
```

默认训练入口会读取：

```text
计算有限元数据/comsol_hdf5/*.h5
计算有限元数据/4_Combined_Master_Dataset.json
```

每个 HDF5 文件名必须与 JSON 中的 `case_id` 一致，例如：

```text
Case_0001.h5 <-> case_id=Case_0001
```

正式训练前建议等待全部 COMSOL 工况完成。计算过程中新增 HDF5 会改变 80%/10%/10% 数据划分。

## 5. 开始训练

最简单的启动方式：

```powershell
conda activate pinn
python transolver_self\train.py
```

默认参数：

```text
epochs=100
batch_size=4
learning_rate=1e-4
hidden_size=256
layers=8
heads=8
slice_num=32
dropout=0
mlp_ratio=1
gradient_clip=1
seed=42
device=auto
```

推荐显式记录参数：

```powershell
python transolver_self\train.py `
  --data-root "计算有限元数据\comsol_hdf5" `
  --epochs 100 `
  --batch-size 4 `
  --learning-rate 1e-4 `
  --hidden-size 256 `
  --layers 8 `
  --heads 8 `
  --slice-num 32 `
  --seed 42
```

`--device auto` 会优先使用 CUDA，没有 CUDA 时使用 CPU。也可以明确指定：

```powershell
python transolver_self\train.py --device cuda
python transolver_self\train.py --device cpu
```

## 6. 训练输出

控制台每个 epoch 输出：

```text
train_mse: 训练集归一化增量 MSE
valid_mse: 验证集归一化增量 MSE
p_rmse:    单步压力 RMSE
T_rmse:    单步温度 RMSE
lr:        当前学习率
```

模型文件默认保存在：

```text
transolver_self/checkpoints/last.pt
transolver_self/checkpoints/best.pt
transolver_self/checkpoints/epoch_0010.pt
transolver_self/checkpoints/training_config.json
```

含义：

```text
last.pt:       最近一个完成的 epoch
best.pt:       valid normalized MSE 最低的模型
epoch_XXXX.pt: 按 --save-every 周期保存
```

训练配置会写入 `training_config.json`。模型和 Normalizer 统计都保存在 checkpoint 中。

## 8. 断点恢复

使用默认结构训练时：

```powershell
python transolver_self\train.py `
  --resume transolver_self\checkpoints\last.pt
```

如果原训练使用了非默认结构，恢复时必须再次传入完全相同的结构参数，例如：

```powershell
python transolver_self\train.py `
  --hidden-size 192 `
  --layers 6 `
  --heads 8 `
  --slice-num 24 `
  --resume transolver_self\checkpoints\last.pt
```

恢复内容包括模型、Normalizer、optimizer、scheduler、epoch、global step 和最佳验证损失。

不要用 MeshGraphNet checkpoint 恢复 Transolver，也不要混用不同模型结构的 checkpoint。

## 9. 完整时间序列 rollout

使用最佳 checkpoint：

```powershell
python transolver_self\rollout.py `
  --checkpoint transolver_self\checkpoints\best.pt `
  --case-id Case_0300 `
  --steps 150
```

参数说明：

```text
--case-id:     HDF5 工况编号
--start-index: 起始时间索引，默认 0
--steps:       自回归步数，默认预测到最后一帧
--device:      auto、cuda 或 cpu
--output:      输出 .pt 文件或输出目录
```

从中间时刻开始并指定输出文件：

```powershell
python transolver_self\rollout.py `
  --checkpoint transolver_self\checkpoints\best.pt `
  --case-id Case_0300 `
  --start-index 20 `
  --steps 50 `
  --output transolver_self\rollouts\Case_0300_from_20.pt
```

注意：`--steps 1` 表示前进一个 HDF5 时间索引，不表示前进 1 秒。实际物理时间来自 `time_steps`。

## 10. 读取 rollout 结果

```python
import torch

result = torch.load(
    "transolver_self/rollouts/Case_0300_rollout.pt",
    weights_only=False,
)

print(result["case_id"])
print(result["field_names"])
print(result["metrics"])

meshes = result["meshes"]
mesh = meshes[20]

print(mesh.time)
print(mesh.pos.shape)
print(mesh.face.shape)
print(mesh.predicted_fields.shape)
```

每个 `mesh` 是 PyG `Data`：

```python
mesh.pos                  # 当前动态网格坐标 [N,2]
mesh.face                 # 静态拓扑 [3,F]
mesh.predicted_fields     # [p,T] [N,2]
mesh.p                    # 压力 [N,1]
mesh.T                    # 温度 [N,1]
mesh.mesh_region          # 三段区域 [N]
mesh.mesh_motion_weight   # 运动权重 [N]
mesh.node_displacement    # 当前节点位移 [N,1]
mesh.mesh_velocity        # 当前节点速度 [N,2]
mesh.piston_displacement  # 活塞位移
mesh.piston_velocity      # 活塞速度
mesh.time                 # 当前物理时间
mesh.case_id              # 工况编号
```

`meshes[0]` 是真实初始场；`meshes[1:]` 是自回归预测场。网格位置由解析运动规律按每个时间重新计算。

## 11. 与 MeshGraphNet 公平比较

正式实验前执行以下检查：

1. 等待 COMSOL 全部完成并冻结数据目录；
2. 确认两个模型使用相同 JSON；
3. 使用相同 batch size、seed、epoch 和学习率；
4. 使用相同的 train/valid/test 工况；
5. 不改变 `FIELD_NAMES=(p,T)`；
6. 都使用时间索引步长 1；
7. 都按 `best.pt` 做最终评价；
8. 同时报告单步 RMSE 和完整 rollout RMSE；
9. 记录参数量、训练时间和推理时间。

推荐命令保持同口径：

```powershell
python meshGraphNet_self\train.py `
  --epochs 100 --batch-size 4 --learning-rate 1e-4 --seed 42

python transolver_self\train.py `
  --epochs 100 --batch-size 4 --learning-rate 1e-4 --seed 42
```

默认两个模型参数量接近，但内部结构不同：MeshGraphNet 使用动态边特征，Transolver 使用 Physics-Attention。

## 12. 常见问题

### 12.1 找不到 HDF5

错误通常包含：

```text
No .h5 files found
```

处理：

```powershell
python transolver_self\train.py `
  --data-root "D:\1\LJJ\practical_project\Viscous-Damper-Surrogate-Model-main\计算有限元数据\comsol_hdf5"
```

### 12.2 找不到 JSON 或 case_id

确认：

```text
计算有限元数据/4_Combined_Master_Dataset.json
```

也可以显式指定：

```powershell
python transolver_self\train.py `
  --parameters-json "计算有限元数据\4_Combined_Master_Dataset.json"
```

### 12.3 网格边界与 JSON 不匹配

这通常表示 HDF5 和 JSON 工况对应错误，或导出的不是静态液体参考网格。应先检查数据，不建议直接关闭验证。

仅用于诊断时可以：

```powershell
python transolver_self\train.py --no-validate-mesh-domain
```

### 12.4 CUDA 显存不足

优先减小 batch：

```powershell
python transolver_self\train.py --batch-size 1
```

仍不足时再降低模型规模：

```powershell
python transolver_self\train.py `
  --hidden-size 192 `
  --layers 6 `
  --slice-num 24
```

`hidden-size` 必须能被 `heads` 整除。

### 12.5 checkpoint 维度不匹配

恢复时使用与原训练相同的：

```text
hidden-size
layers
heads
slice-num
mlp-ratio
```

可查看 `transolver_self/checkpoints/training_config.json`。

### 12.6 两模型归一化结果不一致

先检查两次训练之间 HDF5 文件数量是否变化。定义相同不等于在不同数据快照上统计值相同。严格对比应冻结文件清单，使用相同顺序和训练参数。

### 12.7 rollout RMSE 明显大于单步 RMSE

这是自回归误差累积的正常现象。单步验证每次使用真实当前场，而 rollout 从第二步开始使用上一时刻预测场。应同时报告两种指标。

```powershell
git -C transolver_self\official_source\Transolver status
```
