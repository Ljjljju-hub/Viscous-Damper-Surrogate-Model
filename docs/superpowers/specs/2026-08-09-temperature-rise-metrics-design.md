# 温升相对误差与分位指标设计

## 目标

在现有测试结果上增加温升 `ΔT` 指标，并在 `项目总结与面试复习.md` 中解释 P50、P95 的含义以及当前结果反映的模型效果。

## 指标定义

每个工况以初始帧为基准：

```text
ΔT_GT(t, x) = T_GT(t, x) - T_GT(0, x)
ΔT_pred(t, x) = T_pred(t, x) - T_GT(0, x)
```

预测和真值使用同一个真实初始温度，因此：

```text
ΔT_pred - ΔT_GT = T_pred - T_GT
```

温升相对 RMSE 为：

```text
sqrt(sum((ΔT_pred - ΔT_GT)^2) / sum(ΔT_GT^2)) * 100%
```

它只使用预测值和 GT，不使用训练集归一化均值或标准差。绝对温度 RMSE（K）继续保留，用于说明实际温差；绝对温度相对 RMSE 不再单独代表温升预测质量。

单点温升相对误差为：

```text
abs(ΔT_pred - ΔT_GT) / abs(ΔT_GT) * 100%
```

对每个工况排除 `abs(ΔT_GT) < 1% * max(abs(ΔT_GT))` 的节点时刻，防止真实温升接近零时分母放大，并记录有效与排除数量。

## 实现方式

新增独立入口 `evaluation_workspace/calculate_relative_metrics.py`，复用已有单步预测 HDF5、rollout PT 和数据集真值：

1. 计算 81 个测试工况的完整单步压力、绝对温度和温升指标；
2. 在相同 10 个工况上计算单步与 150 步 rollout 指标；
3. 将结果写入现有 `relative_metrics.json`；
4. 保存公式、阈值、有效数量、相对 RMSE、P50、P95、P99 和最大值；
5. 不重新执行模型推理，直接复用已有预测结果。

## 文档表述

- P50 是中位数：50% 的有效节点时刻误差不超过该值，表示典型预测水平。
- P95 表示 95% 的有效节点时刻误差不超过该值，剩余 5% 是误差最大的尾部区域。
- P99 和最大值用于检查极端局部风险，不能替代整体指标。
- 模型评价同时报告全局相对 RMSE、P50 和 P95；单步与 rollout 分开分析。
- 温升相对误差与绝对温度相对误差不得混写，因为二者分母不同。

## 验证

1. 验证 `ΔT_pred - ΔT_GT` 与 `T_pred - T_GT` 数值一致；
2. 验证单步和 rollout 使用各工况同一个 GT 初始帧；
3. 验证近零阈值按工况计算；
4. 检查 JSON 中所有结果为有限数值且计数正确；
5. 报告中的数值逐项匹配 JSON，并运行 `git diff --check`。
